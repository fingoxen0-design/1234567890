# 🔥 O‘zbekiston uchun TOP-5 real muammo
**Buxoro sharoitida ham ishlashi mumkin bo‘lgan jiddiy veb-startap yo‘nalishlari.**

### 🥇 1. Ish bajariladi, lekin pulni undirish muammo
**Kimlarda:** Qurilish brigadalari, ustalar, freelancerlar, kichik korxonalar.

**Muammo:** Buyurtmachi ish tugagandan keyin pulni kechiktiradi, kelishilgan narxni inkor qiladi yoki qo‘shimcha ishlar uchun to‘lashdan bosh tortadi. Ko‘pincha kelishuvlar og‘zaki yoki Telegram orqali bo‘ladi.

**Sayt uchun imkoniyat:** Kelishuv, ish bosqichlari, bajarilgan ish dalillari va to‘lov majburiyatlarini yagona tizimda qayd etish.

### 🥈 2. Odamlar qaysi kasbni o‘rgansa ish topishini bilmaydi
**Kimlarda:** Maktab bitiruvchilari, talabalar, kasb o‘zgartirmoqchi bo‘lganlar.

**Muammo:** Odam 6–12 oy kursga qatnaydi, pul sarflaydi, lekin o‘rgangan kasbiga bozorda talab kamligini yoki ish beruvchilar boshqa ko‘nikmalar so‘rashini keyin biladi.

**Sayt uchun imkoniyat:** O‘zbekistondagi haqiqiy vakansiyalarni tahlil qilib, kasblar bo‘yicha talab qilinadigan bilimlar va tajriba darajasini ko‘rsatish.

### 🥉 3. Avtomobilning haqiqiy holatini bilish qiyin
**Kimlarda:** Ishlatilgan avtomobil sotib oluvchilar.

**Muammo:** Mashinaning avvalgi avariyalari, ta’mirlari, haqiqiy yurish masofasi va yashirin texnik nosozliklari haqida to‘liq ma’lumot bo‘lmasligi mumkin.

**Sayt uchun imkoniyat:** Avtomobilning tekshiruv natijalari, servis tarixi va texnik holati haqida tasdiqlangan ma’lumotlarni jamlash.
